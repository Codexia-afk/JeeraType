## 3. "Show HN" Submission (Hacker News)

**Title:** Show HN: JeeraType – 100% offline, cross-platform terminal typing speed test

**Body Text:**
```text
Hey HN,

I built JeeraType, a single-binary terminal typing speed test designed to run 100% offline on macOS, Linux, and Windows.

Why another typing tool?
Many web-based typing tools require an internet connection, account creation, or browser tabs. Existing CLI tools often lack comprehensive analytics or require C dependencies.

Key Features:
- 100% Offline: Wordlists, code snippets, quotes, and color themes are embedded directly inside a single static binary.
- Analytics & Stats: Subcommands for session history (`jeeratype stats`), visual key error heatmaps (`jeeratype stats --heatmap`), and multi-profile leaderboards (`jeeratype stats --leaderboard`).
- Practice Modes: Infinite Zen mode, Punctuation/Numbers toggles, Code mode (Python, JS, Go), Sudden Death mode, and custom wordlist files (`--wordlist`).
- Cross-Platform: Pre-built standalone binaries for Linux, macOS, and Windows.

Code & Binaries: https://github.com/Codexia-afk/JeeraType

Feedback and contributions welcome!
```
